## Overview

An agent provider defines how Sandcastle interacts with a specific AI coding tool. Each provider declares:

- An **env manifest** -- which environment variables it requires
- An **env check** -- validation that runs before the agent starts
- A **Dockerfile template** -- used during `sandcastle init` to scaffold the sandbox

## Built-in Providers

### Claude Code

The default agent provider. Uses Claude Code as the AI coding agent inside the sandbox.

Required environment variables (one of):

| Variable | Description |
| --- | --- |
| `CLAUDE_CODE_OAUTH_TOKEN` | Claude Code OAuth token. Run `npx sandcastle claude-login` to create one with `claude setup-token` and store it in `.sandcastle/.env`. Lets the agent use your Claude subscription instead of an API key. |
| `ANTHROPIC_API_KEY` | Anthropic API key (alternative to `CLAUDE_CODE_OAUTH_TOKEN`) |

`npx sandcastle claude-login` runs `claude setup-token` (browser sign-in), asks for the printed token with masked input, checks its format and writes `CLAUDE_CODE_OAUTH_TOKEN` with `CLAUDE_CODE_OAUTH_TOKEN_ISSUED_AT` to `.sandcastle/.env` (mode 0600, other entries kept). `--verify` first confirms the token with one minimal request that uses only the token; `--force` replaces a configured token. `sandcastle init --agent claude-code` offers the same login (`--claude-login true|false`).

Setup tokens last one year; the recorded issue date lets Sandcastle warn 30 days before expiry. `claude auth status` reports any token as logged in without validating it, so Sandcastle checks it locally instead: declared in `.sandcastle/.env`, `sk-ant-oat…` format, not expired, and not shadowed by `ANTHROPIC_API_KEY` (non-interactive runs may bill the API key instead of the subscription).

Plus:

| Variable | Description |
| --- | --- |
| `GH_TOKEN` | GitHub personal access token |

### OpenCode

Uses OpenCode as the AI coding agent. Sandcastle runs it with `--format json` and parses the structured event stream to surface live text, tool calls, and the session ID.

Required environment variables:

| Variable | Description |
| --- | --- |
| `GH_TOKEN` | GitHub personal access token |

## Custom Providers

Agent providers are swappable. To add support for a different AI coding tool, create a new provider that implements the agent provider interface with its own env manifest, env check, and Dockerfile template.
